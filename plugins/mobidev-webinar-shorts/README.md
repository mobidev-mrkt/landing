# mobidev-webinar-shorts

Claude Code plugin: a MobiDev webinar recording (Google Drive link) → 10 vertical YouTube Shorts (20–60 s) in the
MobiDev brand, with CTA end cards (5 × Free AI SDLC Readiness Discovery, 5 × AI-Driven Modernization Readiness
Checklist), titles, descriptions and Google Drive folders. Two approval stops: the 10 moments, then hooks and scene texts.

Requires: Claude Code (cloud or local with ffmpeg, Node.js, Python 3.9+) and the **it-reelsmaker** plugin enabled.
Start: "Ось новий вебінар, зроби шортси: <Drive link>". The method and its numbers: `skills/webinar-shorts/SKILL.md`.
