# Webinar Shorts (it-reelsmaker)

Brand profile and settings for making vertical YouTube Shorts from MobiDev webinars.

- `brands/mobidev/`: brand profile (`brand.json`), design rules (`rules.md`), CTA library (`cta.md`), logo in `assets/`.
- Source: "Webinar 13", https://drive.google.com/file/d/1338QXz3EPlWeKAfrZW8-uBPUBDHigDUf/view
- Brief: 10 Shorts, 20–60 s, English subtitles, style "Brand", subtitles "Accent".
  CTA: 5 videos "Free AI SDLC Readiness Discovery", 5 videos "Download the free AI-Driven Modernization Readiness Checklist".
- Before editing, set `remotion_dir` in `it-reelsmaker.json` to the Remotion project (`kit.py new <folder>`, then `npm install`).
